# Todo PWA v1.0.6

這一版依照最新確認效果圖重做主畫面，可直接部署到 GitHub Pages，不需要 Node.js、PHP 或伺服器資料庫。

## v1.0.6 主要變更
- 第一排固定為「全部 / 未完成 / 已完成 / 今天 / 篩選」五個實體按鈕。
- 移除原本獨立的類別 / 優先級篩選列，不再多佔一行版面。
- 「篩選」按鈕開啟整合面板，可設定：類別、優先級、日期範圍、只顯示已完成、只顯示近期 7 天。
- 有套用進階篩選時，「篩選」按鈕會顯示啟用狀態與提示點。
- 優先級內建為「高 / 一般 / 低」，新增待辦初始預設「一般」。
- 主輸入框改為單行起始高度，文字增加時自動換行與放大。
- 主畫面待辦改為最新效果圖的緊湊列表：左側完成框、中央內容、右側三點功能皆垂直置中。
- 三點按鈕：淺色模式黑色、深色模式白色。
- 主畫面底部左側顯示目前清單數量，右側顯示 v1.0.6。
- 左側選單調整為：待辦事項、日曆、分類管理、優先級管理、備份與還原、頁籤管理、設定、關於。
- 頁籤管理只調整前四個頁籤；「篩選」固定在最右側，不參與排序。
- 搜尋按鈕放在右上角，搜尋不改動原始資料。

## 資料安全
- 沿用 IndexedDB：`todo-pwa-db`。
- 從 v1.0.0～v1.0.4 更新到 v1.0.6，不會主動清除既有待辦。
- Service Worker 只更換網站快取，不執行 `indexedDB.deleteDatabase()`。
- 舊版預設優先級「中」如果未被使用者自訂，會安全改名為「一般」。
- 備份仍支援 JSON 匯出、完整性檢查、合併匯入與取代匯入。

## GitHub Pages 部署
1. 解壓縮 `todo-pwa-v1.0.6.zip`。
2. 將資料夾內所有檔案上傳到 GitHub Repository 根目錄。
3. GitHub → Settings → Pages。
4. Source 選 `Deploy from a branch`。
5. Branch 選 `main`，資料夾選 `/(root)`。
6. 等待 GitHub Pages 部署完成。

更新舊版時，直接用 v1.0.6 檔案覆蓋 Repository 內的舊程式檔即可。不要清除手機瀏覽器的網站資料，既有 IndexedDB 紀錄會保留。

## 主要檔案
- `index.html`：畫面結構。
- `style.css`：元件樣式與 v1.0.6 最新效果圖版面。
- `layout-config.css`：集中管理主要尺寸、字體、顏色。
- `layout-spec.md`：所有重要版面數值說明。
- `app.js`：待辦、篩選、搜尋、日曆、管理功能。
- `db.js`：IndexedDB。
- `backup.js`：備份、驗證、匯入。
- `version.js` / `version.json`：版本檢查。
- `service-worker.js`：PWA 離線快取與更新。
